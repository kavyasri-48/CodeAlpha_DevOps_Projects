# CodeAlpha DevOps Projects

This repository contains DevOps projects completed as part of the **CodeAlpha DevOps Internship Program**.

## 📁 Projects

### 1. CodeAlpha Docker Web Server

A Dockerized Nginx web server hosting a custom HTML/CSS webpage.

The project demonstrates how to build a Docker image, run a container, configure port mapping, and serve a custom webpage through Nginx.

**Technologies:**

* Docker
* Nginx
* HTML
* CSS
* Linux / Ubuntu
* Git
* GitHub

**Key Concepts:**

* Dockerfile
* Docker images
* Docker containers
* Docker build and run
* Port mapping
* Container lifecycle
* Nginx web server
* Container logs
* Basic troubleshooting

**Project Folder:** `CodeAlpha_DockerWebServer`

**Project:** [CodeAlpha Docker Web Server](./CodeAlpha_DockerWebServer)

---

### 2. CodeAlpha Jenkins Remoting Project

A Jenkins Controller-Agent project demonstrating remote build execution using **Jenkins Remoting**.

The Jenkins Controller manages and schedules jobs, while the remote Linux Agent executes the assigned build tasks.

**Technologies:**

* Jenkins
* Jenkins Remoting
* Jenkins Agents
* Jenkins Executors
* Java
* Linux / Ubuntu
* Git
* GitHub
* Shell

**Key Concepts:**

* Jenkins Controller-Agent architecture
* Jenkins Remoting
* Remote build execution
* Distributed builds
* Node labels
* Executors
* Build automation
* Job scheduling
* Linux-based build execution

**Project Folder:** `CodeAlpha_Jenkins_Remoting`

**Project:** [CodeAlpha Jenkins Remoting Project](./CodeAlpha_Jenkins_Remoting)
